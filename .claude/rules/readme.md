# README 規約（README編集時のみロードされる）

## 必須の配置

`src/` `scripts/` `tests/` には `README.md` を必ず置く。
中身を変更したら、**同じコミットで README も更新する**（別コミットに分けない）。

## 各READMEに書くこと

| ディレクトリ | 書く内容 |
|---|---|
| `src/README.md` | モジュール構成・各モジュールの責務・モジュール間の依存関係（図） |
| `scripts/README.md` | 各スクリプトの目的・実行順序・入出力ファイル（データフロー図） |
| `tests/README.md` | テストの分類（unit / integration 等）・実行方法・カバー範囲 |

## 共通の構成

```markdown
# <ディレクトリ名>

このディレクトリが何を担当するかの1〜2行。

## 構成

（Mermaid図。処理の流れ・依存関係を1枚に）

## ファイル一覧

| ファイル | 役割 | 入力 | 出力 |
|---|---|---|---|

## 使い方

（代表的な実行コマンド。make ターゲットがあればそれを優先して書く）
```

## 原則

- **図を必ず入れる。** 処理の流れ・依存関係は文章より図が速い。作り方は `.claude/rules/mermaid.md` に従う
- **推測で書かない。** 依存関係は `grep` で import と入出力パスを実測してから書く。
  実測結果と既存の記述が食い違ったら、実測が正しい
- ファイル一覧の表は、パスと役割の対応が1行で分かる粒度にする。詳細は各ファイルのdocstringへ
- 概念そのものの解説（「過学習とは何か」等）はREADMEに書かず、Wikiへリンクする
  （`.claude/rules/wiki.md` 参照）
