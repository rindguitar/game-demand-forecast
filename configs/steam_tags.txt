# タグの判定（1行1タグ・# はコメント）
#
# ①ゲーム要素の語彙（tag_semantics.element_tags）に使うタグをここで判定する。
# 基準は「遊ぶ前に分かる、ゲームの中身」。次の2つは①にしない。
#
# 見出し:
#   [not_content]  ゲームの中身を表さない … 開発規模・販売形態・シリーズ・導入の作り
#   [impression]   遊んだ結果の感想        … 遊ぶ前には分からない
#   [element]      上の2つ以外            … ①ゲーム要素
#
# Steamタグは閉じた語彙で、ゲームを増やしてもほぼ増えない。そのため全タグに一度だけ
# 判定を付ける。判定の無いタグが母集団に出たら element_tags() が ValueError で止まるので、
# 追記して判定すること。
