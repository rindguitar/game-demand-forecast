# の第一段（ルール）で使う。ここに載っていない語しか持たないトピックは
# ①ゲーム要素 と判定する（要素が本命で、それ以外を差し引く形にしている）。
#
# 分類:
#   [quality]      ②品質・運営      … 不具合・性能・運営の対応・コミュニティの荒れ
#   [business]     ③ビジネス条件    … 価格・課金モデル。需要量に合算せず阻害要因の別枠に置く
#   [contentless]  中身なし          … 賞賛/罵倒・メタ言及・プレイ時間。需要の手がかりにならない
#   [propernoun]   固有名詞          … 開発元・キャラ名・他タイトル。束ねる対象から外す
#   （どれにも当たらない）①ゲーム要素 … 需要スコアの対象
#
# 語彙は 2026-09-06 の本番実行（455トピック）で、週10件以上の60トピックの
# キーワードを目視して作った。増やすときは実データのキーワードから採ること。
#
# 一般語と紛れる語は入れない（proper_nouns.txt と同じ方針）。
#   例: "run"（動作 / 走る）、"support"（サポート体制 / 対応プラットフォーム）は入れない
